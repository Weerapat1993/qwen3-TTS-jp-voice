## 🟢 TTS-1006: /say — เพิ่ม language override กัน TTS ออกเสียงผิดภาษา (lang_code ผ่าน daemon protocol)

Status: Done
Priority: High
Source: feedback ผู้ใช้ 2026-08-30 (ต่อจาก TTS-1005 `/transcribe`)
Plan: docs/superpowers/plans/2026-08-30-say-language.md

### Summary
เพิ่มตัวเลือกระบุภาษาให้ path TTS (`/say`, `qwen_clone_tts.py --lang`, daemon) เพื่อกันเคสออกเสียงผิดภาษา เช่นข้อความญี่ปุ่นถูกอ่านด้วยสำเนียงผิด ปัจจุบันไม่มี script ไหนส่ง `lang_code` ให้ `generate_audio()` เลย → ใช้ค่า default ของ mlx-audio (`"en"`) เสมอ ไม่ว่าข้อความจะเป็นภาษาอะไร งานนี้ thread ค่า `lang` ผ่านตั้งแต่ `/say` option → `_try_daemon` JSON → daemon `handle_request` → `_generate` → `generate_audio(lang_code=...)` พร้อมใส่ `lang` ใน `_cache_key` และคง default = `auto` เพื่อไม่เปลี่ยนพฤติกรรมเดิม (Thai / Hermes `--stdin`)

### Context
- Qwen3-TTS-12Hz รองรับ `lang_code` จริง — `models/Qwen3-TTS-12Hz-1.7B-Base-8bit/config.json` → `talker_config.codec_language_id` มี: `chinese, english, german, italian, portuguese, spanish, japanese, korean, french, russian` (+ `auto`)
- **ไทยไม่อยู่ในลิสต์** → ภาษาไทยจะ fall through เป็น `auto` เสมอ (การเพิ่ม option ไม่ทำให้ไทยแย่ลง แต่ก็ช่วยไม่ได้)
- `mlx_audio/tts/generate.py` : `generate_audio(..., lang_code="en", ...)` → forward เข้า `model.generate(lang_code=...)` → lookup ใน `codec_language_id`; ไม่เจอ → `language_id=None` → fallback path
- เส้นทางที่ต้องแก้ (จาก CLAUDE.md — protocol เปลี่ยนต้องแก้ทั้งสองฝั่ง):
  - `qwen_clone_tts.py`: `_run()` เรียก `generate_audio(...)` (บรรทัด ~268) ไม่มี `lang_code`; `_try_daemon()` ส่ง JSON `{text, instruct, out_path, voice, format}` (บรรทัด ~140) ไม่มี `lang`; ยังไม่มี argparse `--lang` (แต่ docstring บรรทัด 6 สัญญาไว้แล้ว `[--lang th|en|...]`)
  - `tts_daemon.py`: `handle_request()` อ่าน `req.get(...)` (บรรทัด ~240); `_generate()` เรียก `generate_audio(...)` (บรรทัด ~181/210); `_cache_key(text, instruct, voice)` (บรรทัด 91) — **ต้องเพิ่ม lang เข้า hash**; module docstring documents protocol (บรรทัด 5)
  - `discord_say_bot.py`: `/say` command → `_try_daemon(spoken, wav_path, instruct, DEFAULT_VOICE, "wav")` (บรรทัด ~281)
- External consumer: Hermes shell out `qwen_clone_tts.py --stdin <in> <out>` (ดู `README_HERMES.md`) — default `lang` ต้อง = `auto` เพื่อไม่พังผู้ใช้ภายนอก
- `instruct` (mood preset) เป็น style directive แยกจาก `lang_code` — ส่งคู่กันได้

### Scope
- `qwen_clone_tts.py`:
  - เพิ่ม arg `--lang` (default `auto`), plumb ผ่าน `_run(..., lang)` → `generate_audio(lang_code=lang)` (fallback path) และ `_try_daemon(..., lang)` → ใส่ `"lang"` ใน JSON request
  - `--stdin` mode: รับ `--lang` ด้วย (default `auto`)
- `tts_daemon.py`:
  - `handle_request`: `lang = req.get("lang", "auto")`
  - `_generate(..., lang)` → `generate_audio(lang_code=lang)` ทั้ง single และ multi branch
  - `_cache_key(text, instruct, voice, lang)` — hash `lang or "auto"` (client เก่าที่ไม่ส่ง lang ยัง cache-hit request เดิมได้)
  - telemetry `log_event` เพิ่ม field `lang`
  - อัปเดต module docstring protocol section
- `discord_say_bot.py`: `/say` เพิ่ม `language:` (app_commands.choices, subset ของ `codec_language_id` + `auto`) → ส่งเข้า `_try_daemon`
- `README.md`: §Protocol request shape, §Discord Bot `/say` docs, §CLI Reference `--lang`
- `README_HERMES.md`: อัปเดตถ้ามี section ที่ระบุ request shape / CLI flags ของ `--stdin`

### Non-goals
- เพิ่ม Thai เข้า `codec_language_id` (โมเดลไม่รองรับ — ไทยใช้ `auto` เท่านั้น)
- `/transcribe` (มี `language:` แล้วจาก TTS-1005)
- ระบุภาษาต่อบรรทัดใน `/say file:` batch เดียว (ทั้ง batch ใช้ค่าเดียว)
- เปลี่ยน default เป็นอย่างอื่นนอกจาก `auto` (ต้องคง backward compat)
- แตะ voice-clone ref audio / mood preset instruct strings

### Validation
- Manual CLI: `.venv/bin/python qwen_clone_tts.py --text "こんにちは、元気ですか" --lang japanese --out outputs/ja.wav` → ฟัง; เทียบกับ `--lang auto`
- Regression CLI: `.venv/bin/python qwen_clone_tts.py --text "สวัสดีค่ะ วันนี้อากาศดี" --out outputs/th.wav` (ไม่มี `--lang`) → เสียงไทยปกติ
- Daemon: start `tts_daemon.py` ใหม่ → ยิง request ผ่าน client ทั้งแบบมี `lang` และไม่มี → ตรวจ response JSON, `TTS_TELEMETRY_LOG` มี `lang`, `TTS_CACHE_DIR` มีไฟล์แยกตามภาษา
- Daemon backward compat: ยิง JSON ดิบ `{"text":...,"out_path":...,"voice":"Liino"}` (ไม่มี `lang`) → สำเร็จ, cache-hit ไฟล์เดิมถ้ามี
- Discord live: `/say text:"..." language:japanese` และ `/say text:"สวัสดี"` (ไม่ระบุ)
- Round-trip: `/transcribe` (ja) → `.txt` → `/say file:` + `language:japanese` → Liino พูดญี่ปุ่นทีละบรรทัด
- `.venv/bin/python -m pytest -q` เขียว (เพิ่ม test `_cache_key` แยกตาม lang ถ้าเข้าเกณฑ์ `coding-style.md`)
