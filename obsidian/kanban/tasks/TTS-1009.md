## 🎙️ TTS-1009: Discord slash command `/voice-clone` + `/say` เลือกเสียงได้

Status: Backlog
Priority: Medium
Source: คำขอผู้ใช้ (Wyitz) ใน Discord — อยาก clone เสียงใหม่จาก Discord โดยอัปโหลด mp3/wav, ถอดเสียงอัตโนมัติ (reuse feature transcribe), กำหนด Voice Instruction ของตัวละครเอง และแก้ไขภายหลัง

### Summary
ปัจจุบัน `discord_say_bot.py` ล็อกเสียง Liino (`qwen_clone_tts.py` stdin mode hardcode `--voice Liino`) และการเพิ่มเสียงใหม่ต้อง copy ไฟล์เข้า `voices/` + เขียน transcript เองแบบ manual อยากได้ flow ครบวงจรบน Discord:

```
/voice-clone create  name:<ชื่อ> file:<.mp3/.wav> [instruction:<บรรยายน้ำเสียง>] [overwrite:<bool>]
/voice-clone list
/voice-clone edit    name:<ชื่อ> [instruction:<ข้อความใหม่>] [rename:<ชื่อใหม่>]
/voice-clone delete  name:<ชื่อ>
/voice-clone test    name:<ชื่อ> [text:<ข้อความทดสอบ>] [mood:<preset>]
```

และเพิ่ม optional `voice:` parameter ให้ `/say` (default = Liino เหมือนเดิม เมื่อไม่ระบุ)

### Context
- `voices/Liino.wav` + `voices/Liino.txt` เป็น default voice — ห้ามทับโดยไม่ตั้งใจ (guard ด้วย `overwrite:true`)
- `/transcribe` (TTS-1005) มี Whisper STT ผ่าน `stt_transcribe.py` (`run_stt`, `probe_duration`) ใช้ซ้ำได้เลยสำหรับถอดเสียงอ้างอิง → เขียนเป็น `voices/<Name>.txt`
- Voice Instruction = คำบรรยายน้ำเสียง/นิสัยตัวละคร แนวเดียวกับ `MOOD_PRESETS` (สั้น, ภาษาอังกฤษ, "trait, trait, pacing") — เก็บเป็น `voices/<Name>.instruct.txt` เป็น default instruction ประจำเสียง
- `resolve_instruct()` ใน `qwen_clone_tts.py:103` ตอนนี้ fallback เป็น `MOOD_PRESETS["default"]` เสมอ — ต้องเพิ่ม parameter รับ `voice_default` (อ่านจาก `<Name>.instruct.txt`) โดยคงลำดับความสำคัญ: mood ที่เลือกตอน /say > instruction ประจำเสียง > default
- `qwen_clone_tts.py` รองรับ `--voice <name>` + `--instruct` อยู่แล้ว; daemon protocol (`_try_daemon()` ↔ `handle_request()`) ส่ง field `voice` ผ่านได้ — ตรวจว่า bot path ใช้ daemon fast path ได้จริงเมื่อ voice ≠ Liino (cache key มี voice อยู่แล้ว)
- Discord bot limit ขนาด attachment ~8-25MB ตาม boost level; ffmpeg (`brew install ffmpeg`) มีอยู่แล้วสำหรับ convert/concat

### Scope
- **`discord_say_bot.py`** — เพิ่ม command group `/voice-clone` (create/list/edit/delete/test):
  - `create`: ตรวจสกัดไฟล์ (mp3/wav/m4a/ogg) → ffmpeg แปลง mono wav + trim ให้ 5-15 วิ (หรือ `silenceremove`) → `voices/<Name>.wav` → Whisper ถอด → `voices/<Name>.txt` → เขียน `voices/<Name>.instruct.txt` ถ้ามี instruction → ตอบกลับพร้อมสคริปต์ที่ถอดได้ให้ผู้ใช้ตรวจ
  - `list`: สแกน `voices/*.wav` + แสดง instruction ของแต่ละเสียง
  - `edit`: แก้ `instruction` และ/หรือ `rename` (rename ต้องย้าย .wav/.txt/.instruct.txt ครบ + ตรวจชื่อใหม่ไม่ซ้ำ)
  - `delete`: ลบไฟล์ทั้ง 3 แบบ confirm ชัดเจน (ป้องกันลบ Liino หรือให้ต้อง `confirm:true`)
  - `test`: generate ประโยคทดสอบด้วยเสียงนั้น → ส่งไฟล์เสียงกลับ (ผ่าน daemon fast path)
- **`discord_say_bot.py` `/say`** — เพิ่ม optional `voice:` choice/autocomplete จากการสแกน `voices/*.wav`, default Liino
- **`qwen_clone_tts.py`** — `resolve_instruct()` รับ voice-default; helper อ่าน `<Name>.instruct.txt` (เป็น single source of truth ของ constants ตาม CLAUDE.md)
- **sanitize ชื่อ** — `name` จำกัด `[A-Za-z0-9_]`, lowercase, ปฏิเสธ path traversal
- **docs** — README § Discord Bot + CLI reference

### Non-goals
- เปิด long-text chunking ที่ gate ปิดอยู่
- upload หลายคลิปต่อเสียงเดียว (concat) — ทำภายหลังถ้าต้องการ
- permission/role gating ของ slash command (ทุกคนใน guild ใช้ได้) — เพิ่มภายหลังถ้าผู้ใช้ต้องการ
- แก้ daemon cache/queue logic

### Acceptance Criteria
- [ ] `/voice-clone create` ด้วย mp3 จริง → ได้ `voices/<Test>.wav` + `.txt` + `.instruct.txt` ครบ, บอทตอบพร้อม transcript
- [ ] create ซ้ำชื่อเดิมโดยไม่ใส่ `overwrite:true` → ถูกปฏิเสธ ไม่ทับไฟล์เดิม
- [ ] create ชื่อ Liino → ต้องมี guard พิเศษ (reject หรือ `overwrite:true` ชัดเจน)
- [ ] `/say voice:<ชื่อใหม่>` → ออกเสียงด้วยเสียงใหม่ผ่าน daemon fast path; ไม่ใส่ `voice:` → Liino เหมือนเดิม (regression-safe)
- [ ] ลำดับ instruct: mood > voice instruction > default ตรวจด้วย unit test ของ `resolve_instruct()` ตัวใหม่
- [ ] `/voice-clone edit` เปลี่ยน instruction แล้ว `/say` ใช้ค่าใหม่ทันที (ไฟล์ instruct.txt ถูกอ่านตอน generate)
- [ ] `/voice-clone list` / `delete` / `test` ทำงานถูกต้อง, delete Liino ต้องยากโดยเจตนา
- [ ] ชื่อที่มีอักขระแปลก (`../x`, มี space, emoji) ถูก sanitize/reject
- [ ] `.venv/bin/python -m pytest -q` เขียว

### Validation
- ทดสอบ create → test → `/say voice:` บน Discord จริงด้วยคลิปเสียงทดสอบ
- pytest unit: sanitize, resolve_instruct ลำดับใหม่, การเขียน/อ่าน `.instruct.txt`
- Regression: `/say` แบบเดิม (ไม่ใส่ voice) + `/transcribe` ยังทำงานเหมือนเดิม
