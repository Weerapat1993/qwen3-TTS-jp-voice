## 🟢 TTS-1002: ?say รับข้อความหลายบรรทัด (array) + auto mood จาก emoji

Status: Backlog
Priority: Medium
Ref: idea จาก Wyitz (2026-08-30, thread นี้)

### Summary
ต่อยอด `?say` จาก TTS-1001 ให้ (1) รับข้อความหลายบรรทัด — 1 บรรทัด = 1 ประโยค แล้ว generate + เล่นเรียงคิวตามลำดับ, (2) auto-detect mood จาก emoji ในแต่ละประโยค โดย map emoji → `MOOD_PRESETS` ที่มีอยู่

### Context
- TTS-1001 (`?say <ข้อความ> [--mood <preset>]`) เสร็จ DONE — playback queue ต่อ guild, idle-leave, reuse `MAX_CHARS`/`MOOD_PRESETS`/`resolve_instruct`/`_try_daemon` จาก `qwen_clone_tts.py`
- `_parse_say_args()` ใน `discord_say_bot.py` parse `--mood` อยู่แล้ว — emoji auto-detect เป็น layer ใหม่บนเส้นทางนี้
- daemon มี response cache ต่อ (voice, text, instruct) — ประโยคเดียวกันคนละ mood จะ cache แยกกันเอง ไม่ต้องแตะ daemon

### Scope
- `?say` รับ multi-line: แยกข้อความด้วย newline ได้ (1 บรรทัด = 1 ประโยค) — generate ทุกบรรทัดแล้วเล่นเรียงคิวตามลำดับบรรทัด
- Emoji auto-mood: ต่อ 1 ประโยค หา emoji ตัวแรกที่เจอ (เจอกี่ตัวก็ใช้ตัวแรก) แล้ว map เป็น mood preset
- Emoji ที่ใช้กำหนด mood จะถูก **ตัดออกจากข้อความที่พูด** (พูดเฉพาะตัวอักษร)
- `--mood <preset>` ที่พิมพ์เองชนะ emoji เสมอ (explicit > auto) — ตัดสินใจแล้วกับผู้ใช้ (2026-08-30)
- ผู้ใช้ตอบคำถาม design แล้ว: array = แยกบรรทัด, emoji ตัวแรกต่อประโยค, ตัด emoji ออกจากข้อความพูด

### Acceptance Criteria
- `?say` ด้วยข้อความ 2-3 บรรทัด → เล่นเรียงตามลำดับบรรทัด ไม่ทับกัน
- `?say 😄สวัสดี` → พูด "สวัสดี" ด้วย mood ตาม map ของ 😄, ตัด emoji ออก
- `?say --mood excited 😄สวัสดี` → ใช้ `--mood excited` เสมอ (ไม่สน emoji)
- บรรทัดที่ไม่มี emoji → ใช้ mood default
- บรรทัดว่าง/whitespace ล้วน → ข้าม
- ความยาวรวมของข้อความที่จะพูด (หลังตัด emoji) เกิน MAX_CHARS → reject ด้วย error ชัดเจน
- daemon ล่ม → error เหมือนเดิม ไม่ค้าง (policy เดียวกับ TTS-1001)

### Validation
- รันจริงใน Discord VC: multi-line, emoji auto-mood, `--mood` override emoji, บรรทัดว่าง, เกิน MAX_CHARS
- ตรวจ playback เรียงคิวตามลำดับ (ffmpeg exit 0 ทุกไฟล์, ไม่ซ้อน)
- ตรวจ emoji→mood mapping เป็น pure logic — พิจารณาเขียน unit test ตาม coding-style.md ตอน implement
