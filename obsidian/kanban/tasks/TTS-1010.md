## 🟢 TTS-1010: `/say voice:` + configurable default voice + `resolve_instruct()` voice-default

Status: Done
Priority: Medium
Source: แยกจาก TTS-1009 (brainstorming gate) + คำขอผู้ใช้ (2026-08-30) — อยากตั้งเสียงหลักเองผ่าน `/voice-clone set-default <name>` ไม่ต้องผูกกับ Liino อีกต่อไป

### Summary
หลัง TTS-1009 ผู้ใช้ clone เสียงใหม่จาก Discord ได้แล้ว แต่ `/say` ยังล็อกเสียง Liino (`DEFAULT_VOICE = "Liino"` hardcode ใน `discord_say_bot.py`). ticket นี้:

1. **`/say voice:` param** — เลือกเสียงต่อครั้งได้ (ไม่ระบุ = ใช้ default ที่ตั้งไว้)
2. **configurable default voice** — `/voice-clone set-default <name>` ตั้งเสียงหลัก; `/say` แบบไม่ระบุ `voice:` ใช้ค่านี้ (fallback = `Liino` เมื่อยังไม่เคยตั้ง)
3. **`resolve_instruct()` voice-default** — รับ per-voice instruction จาก `<Name>.instruct.txt`; ลำดับ `mood > voice instruction > default`

### Context
- **ต้องทำหลัง TTS-1009 merge** (พึ่ง `voice_store.py`: `list_voices`, `read_instruction`, `sanitize_name`, `voice_exists`, `RESERVED`)
- `qwen_clone_tts.py:103` `resolve_instruct(mood, instruct, instruct_long)` ตอนนี้ fallback `MOOD_PRESETS["default"]` เสมอ — single source of truth ตาม `CLAUDE.md`
- `qwen_clone_tts.py` `--voice` argparse default = `"Liino"`; Hermes `--stdin` path hardcode `--voice Liino` (`README_HERMES.md`)
- `discord_say_bot.py` — `DEFAULT_VOICE = "Liino"` (line ~55); `/say` loop เรียก `_try_daemon(spoken, wav_path, instruct, DEFAULT_VOICE, "wav", lang)`; `/voice-clone test` ก็ resolve instruct inline อยู่ (จะรวมกับ `resolve_instruct()` ใหม่ได้)
- daemon `_cache_key()` มี `voice` อยู่แล้ว, `handle_request()` อ่าน `voices/<voice>.wav`+`.txt` ได้ — **ไม่ต้องแก้ daemon**
- `voice_store.RESERVED = {"liino"}` ตอนนี้ผูก literal — เมื่อ default เปลี่ยนได้ ต้อง review ว่า protect อะไรบ้าง

### Scope
- **`voice_store.py`** — เพิ่ม:
  - `DEFAULT_MARKER` = `voices/.default` (ไฟล์บรรทัดเดียวเก็บชื่อเสียง)
  - `FALLBACK_VOICE = "Liino"` (เสียงที่ ship มากับ repo — ใช้เมื่อยังไม่เคยตั้ง default หรือไฟล์ `.default` ชี้เสียงที่ถูกลบ)
  - `get_default_voice() -> str` — อ่าน `.default`; ถ้าไม่มี/ชื่อในไฟล์ไม่มี `.wav` จริง → คืน `FALLBACK_VOICE`
  - `set_default_voice(name) -> None` — `name` ต้อง sanitize + `voice_exists` แล้ว; เขียน `.default`
  - `is_protected(name) -> bool` — แทน/เสริม `is_reserved`: True ถ้า `name` == `FALLBACK_VOICE` (lowercased) **หรือ** == `get_default_voice()` ปัจจุบัน → กัน delete/rename เสียงที่เป็น default อยู่ (ต้อง `set-default` ไปเสียงอื่นก่อน)
- **`qwen_clone_tts.py`** — `resolve_instruct(mood, instruct, instruct_long, voice_default: str | None = None)`; ลำดับ: `instruct_long` > `mood` > `instruct` > `voice_default` > `MOOD_PRESETS["default"]`
- **`discord_say_bot.py`**:
  - `/say` — เพิ่ม `voice:` param (autocomplete จาก `voice_store.list_voices()` — รองรับ >25 เสียง), sanitize; ค่าเริ่มต้น = `voice_store.get_default_voice()`; อ่าน `read_instruction(voice)` ส่งเป็น `voice_default` เข้า `resolve_instruct()`; ส่ง `voice` เข้า `_try_daemon()`
  - `/voice-clone set-default name:<name>` — subcommand ใหม่ในกลุ่ม; validate `voice_exists` → `set_default_voice`; ตอบยืนยัน
  - `/voice-clone list` — mark เสียงที่เป็น default ปัจจุบัน
  - `/voice-clone delete` / `edit rename` — ใช้ `is_protected` แทน `is_reserved` (กันลบ/เปลี่ยนชื่อเสียง default)
  - ลบ `DEFAULT_VOICE` constant hardcode
- **CLI `qwen_clone_tts.py` main** — `--voice` argparse default **คง `"Liino"` literal** (ตัดสินใจแล้ว ดู Decisions — ป้องกัน Hermes ที่เรียก CLI โดยไม่ใส่ `--voice` ไม่ให้เปลี่ยนพฤติกรรมเงียบ ๆ ถ้า default ถูกเปลี่ยนฝั่ง Discord); ยังคง pass `voice_default` จาก `<voice>.instruct.txt` เข้า `resolve_instruct()` เมื่อมีการระบุ `--voice` อื่น
- **docs** — README § Discord Bot (`/say voice:`, `/voice-clone set-default`), § CLI Reference; `CLAUDE.md` (default voice ไม่ hardcode แล้ว); `README_HERMES.md` ถ้า Hermes path เปลี่ยน

### Non-goals
- `/voice-clone` CRUD create/list/edit/delete/test (อยู่ใน TTS-1009 แล้ว)
- long-text chunking, daemon protocol change
- per-guild / per-user default (default เป็น global ต่อ repo)

### Acceptance Criteria
- [ ] `/voice-clone set-default name:<X>` → `/say text:"..."` (ไม่ใส่ voice) ออกเสียงด้วย X
- [ ] ยังไม่เคย set-default → `/say` ใช้ `Liino` เหมือนเดิม (regression-safe)
- [ ] `set-default` ชื่อที่ไม่มีจริง → ephemeral error
- [ ] `.default` ชี้เสียงที่ถูกลบไปแล้ว → `get_default_voice()` fallback `Liino`, ไม่ crash
- [ ] `/say voice:<Y>` → ออกเสียงด้วย Y (override default ครั้งนั้น)
- [ ] `/voice-clone delete` / `edit rename` เสียงที่เป็น default ปัจจุบัน → reject (ต้อง set-default ไปเสียงอื่นก่อน); `Liino` ยัง protect เสมอ
- [ ] ลำดับ instruct `mood > voice instruction > default` — unit test `resolve_instruct()` ครอบทุก branch
- [ ] `resolve_instruct()` เดิมเรียกแบบ 3 args ยังทำงาน (Hermes/CLI ไม่พัง)
- [ ] `/voice-clone list` แสดงว่าเสียงไหนเป็น default
- [ ] `.venv/bin/python -m pytest -q` เขียว

### Validation
- pytest: `get_default_voice`/`set_default_voice`/`is_protected` (tmp dir, ไฟล์ `.default` หาย/ชี้ผิด), `resolve_instruct()` ทุก branch, `/say` voice sanitize
- Manual Discord: set-default → `/say` → `/say voice:` override → delete default (reject) → `/say` เดิม + `/transcribe` regression
- `security-review` gate: `voice` field เข้า daemon จาก user input, `.default` file write

### Decisions
ตอบครบทุกข้อระหว่าง `/kanban plan` (2026-08-30) ผ่าน user confirm — ทุกข้อเลือกตัวเลือกที่เสนอไว้ (Recommended):
- Hermes `--stdin` **คง `--voice Liino` explicit** — ไม่ตาม configurable default (external consumer, ไม่เปลี่ยนพฤติกรรมเงียบ ๆ)
- `resolve_instruct()` ลำดับ: `instruct_long > mood > instruct (explicit) > voice_default > MOOD_PRESETS["default"]` — explicit `--instruct` ชนะ per-voice instruction
- CLI `qwen_clone_tts.py` `--voice` argparse default **คง `"Liino"` literal** — ไม่ตาม `get_default_voice()` (กัน Hermes เปลี่ยนพฤติกรรมเงียบ ๆ เหมือนกัน)
- `voice_store.is_reserved` **เก็บไว้ทั้งคู่กับ `is_protected`** — `is_reserved` เช็ค `RESERVED={"liino"}` literal (ใช้ต่อใน `rename_voice`/`delete_voice` เดิม), `is_protected` เพิ่มเช็ค current-default ทับ ใช้ที่ call site ใหม่ (`/voice-clone delete`/`edit rename`)
