## 🟢 TTS-1000: Add Hermes session discovery and resume helpers

Status: Done
Priority: High

### Summary
เพิ่ม MCP tools สำหรับค้นหา Hermes CLI sessions ที่มีอยู่ และช่วยเลือก `session_id` เพื่อส่ง prompt ต่อเนื่องได้ง่ายขึ้น

### Context
ปัจจุบัน `hermes_prompt` รองรับ `session_id` แล้ว แต่ Claude Code ต้องรู้ session id เองจากผลลัพธ์ก่อนหน้า และไม่มีวิธีค้นหา session ที่เคยสร้างไว้ผ่าน MCP

### Scope
- เพิ่ม tool สำหรับ list sessions ที่เกี่ยวข้องกับ source `mcp-bridge`
- รองรับ limit และ optional working directory filter
- เพิ่ม tool หรือ parameter สำหรับ resume session ที่เลือก
- คง `hermes_prompt` เดิมไว้แบบ backward-compatible
- อัปเดต README และ tests

### Out of Scope
- การค้นหา live Discord gateway sessions
- การ inject เข้า Discord conversation
- การเปลี่ยน behavior ของ Hermes core

### Acceptance Criteria
- Claude Code เรียก MCP แล้วเห็นรายการ session id, title/summary ถ้ามี, เวลาอัปเดต และ working directory
- กรองเฉพาะ session ที่ bridge สร้างได้
- ส่ง session id ที่ได้กลับเข้า `hermes_prompt` แล้ว resume ได้
- session ที่ไม่พบให้ error ที่อ่านเข้าใจได้
- tests ครอบคลุม parsing, filtering และ error path

### Validation
- `uv run --group dev pytest -q`
- MCP `initialize` และ `tools/list` ผ่าน
- manual เรียก list แล้ว resume session จริงหนึ่งรอบ

  - No new resume tool/param — reuse existing `hermes_prompt(session_id=...)`
